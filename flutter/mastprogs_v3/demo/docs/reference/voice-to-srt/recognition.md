# 인식과 검토

## 처리 선택

빠른 처리는 선택한 한 모델을 사용합니다. 모델 선택지는 Qwen 한국어, Whisper large-v3, Whisper large-v2, Whisper large-v3 turbo입니다. 정밀 처리는 비교할 모델을 두 개 이상 골라(Qwen 한국어, large-v3, large-v2, turbo) 같은 원본 구간에 모델별로 순차 적용합니다. 예를 들어 Qwen+large-v3, Qwen+large-v2, Qwen+large-v3+large-v2, Qwen 없이 large-v3+large-v2를 모두 돌려 볼 수 있습니다. 자막 문구와 비교 기준은 Qwen → large-v3 → large-v2 → turbo 순서로 먼저 고른 모델입니다. 모델은 한 번에 하나만 GPU에 올리므로 처리 시간은 고른 모델 수만큼 늘어납니다. 실제 추론과 강제 정렬은 CUDA 장치에서 실행하고 GPU가 준비되지 않으면 실패 상태를 분명히 표시합니다.

완료된 청크의 인식 결과는 모델별로 남아 재개 시 건너뛸 수 있습니다. 비교 조합을 바꿔 다시 실행하면 아직 돌리지 않은 모델만 인식하고, 자막은 새 조합으로 다시 만들며 사용자 수정은 유지합니다. 같은 조합을 다시 실행하면 건너뜁니다. 선택 구간 다시 인식은 선택 구간과 겹치는 청크 전체의 실제 오디오로 모델을 다시 실행합니다. 각 자막의 모델 후보는 새 실행 결과로 바뀝니다. 대응되는 기존 자막의 ID·이력·검토 상태·사용자 수정 텍스트·사용자 조정 표시 시간·최초 인식 원문은 유지하고, 이전 반복·무음 재시도 후보는 해당 청크에 남깁니다. 모델별 입력 구간, 장치, 처리 시간은 결과에 기록됩니다. 모델 간 일치는 정확도 보증이 아닙니다.

## 위험 표시와 시간

비교는 기준 모델(보통 Qwen) 결과와 나머지 모델 각각을 대조하며, 내용이 다른 모델 이름을 위험 문구에 함께 적습니다(예: "Qwen 한국어와 Whisper large-v2 결과의 단어 내용이 다릅니다"). 비교는 공통 오디오 구간과 단어 순서를 기준으로 하며 띄어쓰기·문장부호만 다른 결과는 내용 불일치로 취급하지 않습니다. 누락, 모델 간 차이, 비정상 반복, 거의 무음인 구간의 출력, 읽기 속도와 정렬 실패를 검토 대상으로 표시합니다. VAD와 PCM 에너지는 보조 근거입니다. 실제 반복 발화나 짧은 발화를 의심만으로 삭제하지 않으며 의심 구간은 원음을 듣고 확인해야 합니다.

자막은 영상 자막답게 짧게 나눕니다. 인식 원문의 문장 끝 부호(. ? ! … 등)에서 끊고, 시간은 강제 정렬 단어 시각에서 가져옵니다. 6초 또는 30자를 넘는 문장은 절이 끝나는 말끝(~는데, ~하고, ~해서, ~니까, ~지만 등)이나 쉼표 뒤에서 나눕니다. 인식은 약 20초 청크 단위로 하되, 파형이 준비돼 있으면 경계를 기준 위치 앞뒤 4초 안의 가장 조용한 곳으로 옮겨 문장·단어 중간이 잘리는 일을 줄입니다.

정렬이 실패해도 구간 전체(약 20초)를 자막 하나로 넣지 않습니다. 정렬 모델이 마지막 단어 끝을 구간보다 조금 넘겨 내면 구간 끝으로 잘라 맞추고, 원문에 연결되지 않는 정렬 단위는 건너뜁니다. 정렬이 아예 실패하면 말소리 구간에 글자 수 비율로 시각을 어림해 문장·길이 기준으로 나누고 "단어 시간을 계산하지 못했습니다"로 표시합니다. 인식하는 동안 구간이 끝날 때마다 자막이 화면에 바로 나타납니다.

자막 표시 시간은 말소리에 맞춰 조금 늘립니다. 정렬 모델이 늘어지는 말끝이나 첫소리를 잘라 잡았을 때, 그 경계에서 음성 검출(VAD)상 말소리가 이어지고 있으면 최대 0.3초까지 말소리 시작·끝으로 넓힙니다. 줄이지는 않고 앞뒤 자막을 넘지 않으며, 정렬 결과(단어 시각·발화 시간)는 그대로 둡니다. 파형 크기는 배경음악에도 커지므로 말소리 판단에는 VAD를 씁니다.

Qwen 강제 정렬기는 발화 기준 텍스트를 원본 오디오의 시간에 맞춥니다. 원본 영상의 절대 밀리초 시간으로 저장하고 표시 문구는 모델 원문에서 가져옵니다. 이미 정렬된 자막의 화면 문구나 발화 기준 텍스트를 수정하면 기존 단어 정렬을 오래된 상태로 표시합니다. 한 번도 정렬되지 않은 SRT 가져오기·수동 자막은 정렬 없음 상태를 유지합니다. 0 길이·비정상적인 단어 시간은 정상 정렬로 취급하지 않습니다. 자막 표시 범위는 유효한 구간으로 복구하되 정렬 실패 위험을 남깁니다. 강제 정렬은 발화 내용이 참이라는 증거가 아닙니다.

서로 겹치는 목소리를 화자별로 복원하지 않습니다. BGM 분리와 무거운 화자 분리 기능도 이번 구현 범위에 없습니다. 위험 표시나 반복 재인식 후에도 사람이 원본 음성을 확인해야 합니다.
