# Voice to SRT

Windows에서 게임 영상과 대화의 한국어 자막을 만들고 검토하는 로컬 앱입니다. Go 서버가 편집기 화면을 제공하고 Electron 데스크톱 앱 창이 그 화면을 엽니다. 실제 음성 인식과 단어 시간 계산은 격리된 Python CUDA 작업자가 수행합니다. 외부 CDN은 사용하지 않습니다.

## 실행

1. 저장소 루트의 `start-gpu.bat`를 두 번 클릭합니다. 명령 창에서 `start-gpu.bat -Preflight`로 설치 없이 필수 도구만 점검할 수 있습니다.
2. 최초 실행 시 Go 1.24.1 이상, Python 3.12, FFmpeg/FFprobe, Node.js 22.12 이상(데스크톱 앱 빌드용), NVIDIA 드라이버를 확인합니다. 누락된 일반 도구는 winget으로 설치를 시도합니다. GPU 드라이버는 사용자가 설치해야 합니다.
3. 프로젝트 전용 `.tools/venv-gpu`를 만들고 공식 CUDA 12.8 PyTorch 휠과 잠긴 워커 버전을 설치합니다. `pip check` 및 CTranslate2 경고 검사를 통과한 뒤 Go 앱과 Electron 데스크톱 앱(`.tools/desktop`)을 빌드합니다. 데스크톱 앱을 처음 빌드할 때 npm으로 Electron을 내려받습니다. 음성 인식 모델(Qwen 한국어, 단어 시간 정렬, Whisper large-v3·large-v2)도 이 단계에서 미리 내려받아 첫 자막 만들기가 멈춘 것처럼 보이지 않게 합니다. 처음에는 수 GB를 받으며, 실패해도 경고만 하고 자막을 만들 때 다시 받습니다. turbo는 처음 고를 때 받습니다. 모델 가중치는 첫 인식 때 공식 모델 캐시에 내려받습니다. 이후 같은 소스에서는 설치와 빌드를 재사용합니다.
4. 앱 창이 열리고 명령 창은 닫힙니다. 운영체제 제목 표시줄 대신 앱 상단바에 최소화·최대화·닫기 버튼이 있고, 상단바를 끌어 창을 옮깁니다. 닫기(X)는 앱 종료이며 Go 서버와 Python 작업자도 함께 끝납니다. 작업 중이면 종료 전에 확인합니다. 이미 열려 있으면 기존 창을 앞으로 가져옵니다. 실패 시 명령 창에 한글 진단을 표시하고 창을 유지합니다.
5. 한 번 빌드한 뒤에는 `.tools/desktop/Voice to SRT-win32-x64/Voice to SRT.exe`를 바로 실행해도 됩니다. 소스를 바꾼 뒤에는 `start-gpu.bat`으로 다시 빌드하세요. `start-gpu.bat -NoBrowser`는 앱 창 없이 서버만 명령 창에서 실행합니다(자동화·점검용).

수동 개발 실행: `go build -o .tools/voice-to-srt.exe ./cmd/voice-to-srt` 뒤 `./.tools/voice-to-srt.exe --python .tools/venv-gpu/Scripts/python.exe --worker worker/engine.py`를 실행합니다. UI는 OS가 할당한 `127.0.0.1` 포트에서 제공되며 브라우저로 열립니다. 데스크톱 앱을 개발 중 실행하려면 Go 앱을 빌드한 뒤 `desktop`에서 `npm start`를 실행합니다. 앱 시작 기록은 `%LOCALAPPDATA%/VoiceToSRT/logs/desktop-server.log`에 남습니다.

배치 실행과 수동 Go/worker 실행 모두 기본 모델 캐시는 `%LOCALAPPDATA%/VoiceToSRT/models/huggingface/hub`입니다. `HF_HOME` 또는 `HF_HUB_CACHE`를 실행 프로세스에 명시하면 그 경로를 우선합니다. 실제 사용 중인 경로는 앱의 **진단**에 표시됩니다. 사용자 전체 Python 환경 설정은 변경하지 않습니다.

## 작업 흐름

- 홈에서 파일 경로를 입력하거나, 파일을 고르거나, 앱 창에 끌어놓습니다. 어느 방법이든 원본 경로를 그대로 참조하며 파일을 복사하지 않습니다. 탐색기의 "경로로 복사"처럼 큰따옴표로 감싼 경로도 받습니다. FFmpeg가 PCM 파형을 만들며 4GB 파일을 통째로 메모리에 올리지 않습니다.
- 작업(프로젝트)은 디스크에 저장하지 않습니다. 앱이 실행되는 동안만 유지되고 최근 작업 목록도 없습니다. 앱을 닫거나 "새 작업"으로 바꾸기 전에 결과를 SRT로 내보내세요.
- 빠른 처리는 선택한 한 모델(Qwen 한국어, Whisper large-v3, large-v2, large-v3 turbo)을 사용합니다. 정밀 처리는 비교할 모델을 두 개 이상 골라(예: Qwen+v3, Qwen+v2, Qwen+v3+v2, Qwen 없이 v3+v2) 같은 원본 구간에 순서대로 실행합니다. 자막 문구는 Qwen → large-v3 → large-v2 → turbo 순서로 먼저 고른 모델의 결과를 따릅니다. 조합을 바꿔 다시 실행하면 새 모델만 인식하고 자막을 새 조합으로 다시 만듭니다. 모델들이 일치해도 정확성이 보장되지는 않습니다.
- 단어 정렬 결과는 시간 근거로만 사용합니다. 표시 자막은 인식 원문의 어절·띄어쓰기·문장부호에서 잘라 만들며, 원문에 연결하지 못한 정렬 시간은 실패 위험으로 표시합니다. 정렬이 일부 또는 전부 실패해도 구간 전체를 자막 하나로 넣지 않고, 말소리 구간에 글자 수 비율로 시각을 어림해 문장·길이 기준으로 나눕니다(다시 정렬 필요로 표시). 인식이 진행되는 동안 구간이 끝날 때마다 자막이 목록과 타임라인에 바로 나타납니다. 자막은 영상 자막답게 짧게 나눕니다: 문장 끝에서 끊고, 30자나 6초를 넘으면 절이 끝나는 말끝(~는데, ~하고 등)이나 쉼표 뒤에서 나눕니다. 후보 패널에서 자막 부분의 원문과 모델이 처리한 전체 구간을 구별해 볼 수 있습니다.
- 자막을 선택해 텍스트·시간을 수정하고, 타임라인 양끝을 끌어 경계를 바꿉니다. 나누기·합치기·추가·삭제, 실행 취소·다시 실행, 승인·보류가 가능합니다. 자막을 한 번 누르면 고르기만 하고, 두 번 누르면 그 자막 시작으로 이동합니다. 마우스 휠(타임라인·영상·목록 어디서든)로 이전·다음 자막으로 이동하며, 목록·타임라인·영상은 언제나 커서(재생 위치)의 자막에 맞춰집니다. 나누기는 재생 위치에서 나누고, 끄는 자막 끝은 다른 자막 경계·재생 위치에 자석처럼 붙습니다. 왼쪽 목록 위 "찾아 바꾸기"(Ctrl+F)로 찾은 곳 수를 보고 한 곳씩 넘겨 확인하며 하나 또는 모두 바꿉니다.
- 왼쪽·오른쪽 패널 폭, 영상 높이, 파형 높이는 경계선을 끌어 바꾸고(두 번 누르면 처음 크기) 설정에 기억합니다.
- 숫자 등 화면에 표시할 글자와 실제 발화가 다르면 선택 자막의 `발화 기준 텍스트`를 따로 적습니다. 다시 정렬은 발화 기준 텍스트를 사용하고 SRT는 화면 자막 텍스트를 사용합니다.
- 선택 구간 다시 인식은 해당 청크를 다시 처리합니다. 다시 정렬은 현재 자막만 실제 원본 오디오와 채택된 발화 텍스트로 정렬합니다. 텍스트를 바꾸면 단어 정렬은 오래된 상태로 표시되고 자동 재정렬하지 않습니다. 사용자가 조정한 표시 시간은 재정렬에서 보호합니다.
- 비정상적인 반복 문구나 VAD상 사실상 무음인 구간의 출력은 원후보를 보존한 채 의심 항목으로 표시합니다. 시간이 있는 후보는 출력 구간과 VAD 음성 구간의 겹침도 확인합니다. 근거에는 절대 음성 길이·비율과 PCM 에너지를 남기며, 의심 청크는 더 짧은 창에서 최대 한 번만 다시 인식합니다. 짧은 실제 발화와 반복 발화를 자동 삭제하지 않습니다.
- SRT 가져오기는 UTF-8 BOM과 CP949 계열 입력을 처리하고 잘못된 항목을 행 번호로 알립니다. 내보내기는 시간순 재번호를 적용하며 UTF-8 BOM 옵션을 지원합니다.

## 저장 위치와 프라이버시

- 앱 빌드와 가상환경: 저장소의 `.tools/` (Git 무시)
- 작업(프로젝트): 저장하지 않음. 앱 실행 중 메모리에만 있음
- 앱 실행 기록: `%LOCALAPPDATA%/VoiceToSRT/logs` (실행할 때마다 새로 씀)
- 모델: `%LOCALAPPDATA%/VoiceToSRT/models/huggingface`
- 임시 추출 오디오: `%LOCALAPPDATA%/VoiceToSRT/scratch`; 처리 후 삭제
- 원본 미디어: 선택한 원래 경로를 참조하며 복사·변경하지 않음

음성 인식과 정렬은 로컬에서 실행합니다. 문맥 교정의 Codex CLI, Claude Code, 또는 둘을 함께 쓰는 교차검증은 자막 텍스트·후보·용어·영상 설명을 해당 외부 CLI에 전달합니다. "영상 화면 함께 보내기"(기본 켬)가 켜져 있으면 영상 화면 몇 장(묶음마다 30초에 한 장, 많아야 4장, 가로 768px JPEG)도 함께 보내 화면 속 글자와 상황을 참고하게 합니다. 끄면 화면은 보내지 않습니다. 오디오는 보내지 않습니다. "AI 교정 사용" 옵션(기본 켬)이 켜져 있으면 전체 자막 만들기가 끝난 직후 별도 클릭 없이 전송합니다. 켜 둔 상태에서 "지금 AI 교정 실행"을 누르면 언제든 다시 보내고, 끄면 보내지 않습니다. 이 옵션과 교정 제공자 선택은 `%LOCALAPPDATA%/VoiceToSRT/settings.json`에 기억합니다. 교차검증은 두 CLI가 각자 제안(이유·근거 포함)한 뒤 의견이 갈린 자막만 서로의 제안을 동의·반대와 이유로 검토하며, 사용자가 둘 중 하나를 골라 수락합니다. AI 교정은 문구 교정 전에 자막을 짧은 자막 단위로 다시 나누는 단계를 먼저 거칩니다. 이 단계는 글자를 바꾸지 않고 끊는 위치만 바꾸므로 바로 반영하며(실행 취소 가능), 교차검증에서는 두 AI가 같게 본 곳과 토론으로 합의한 곳만 반영합니다. AI 교정 설정(교정 AI, 영상 설명, 게임 용어, 영상 화면 보내기)은 가운데 "자동 자막" 칸에서 "AI 교정 사용"을 켜면 펼쳐지고, 작업을 시작하면 끝날 때까지 바꿀 수 없습니다. AI 교정은 서버 작업으로 돌며 "자동 자막" 칸에 단계와 처리한 위치를 보이고, 묶음이 끝날 때마다 자막을 바로 반영해 화면이 실시간으로 바뀝니다. AI가 바꾼 자막은 잠깐 초록으로 표시되고 가장 최근에 바뀐 자막으로 이동합니다. AI가 지금 보고 있는 구간은 타임라인에 띠로, 목록에 표시로 보입니다. 그동안 고치는 기능은 모두 비활성 모양으로 잠기고 잠금 안내가 뜹니다. 문장 나누기 때 AI는 파형을 숫자로 받습니다(0.1초마다 소리 크기 0~9, 어절마다 소리 나는 시각). 교차검증에서 두 AI가 끊는 곳을 다르게 보면 서로의 근거와 그 위치의 쉼·소리 크기를 보고 두 번까지 토론해, 합의하면 반영하고 끝까지 다르면 제안으로 남깁니다. AI끼리 주고받은 내용은 떠 있는 "AI 대화" 창에 말풍선으로 보입니다. 앱을 닫거나 작업을 취소하면 Codex·Claude 하위 프로세스(cmd.exe 아래 node.exe까지)를 함께 종료합니다. 실제 사적 녹화의 자동 QA 중 이 버튼을 사용하지 않습니다.

## 한계

겹치는 여러 목소리를 화자별로 복원하지 않습니다. BGM 제거와 화자 분리도 제공하지 않습니다. 모델의 원후보와 의심 근거를 보고 사람이 검토해야 합니다. 정렬된 단어 시간이 전사 내용의 진실성을 보장하지 않습니다. 처리 시간과 자막 품질의 벤치마크 수치는 제공하지 않습니다. CUDA가 준비되지 않으면 CPU로 조용히 전환하지 않으며, SRT 수동 편집은 계속 사용할 수 있습니다. 앱 창(Chromium)이 원본 영상 코덱을 지원하지 않으면 미리보기가 재생되지 않을 수 있습니다. 작업을 저장하지 않으므로 앱이 비정상 종료되면 인식 결과와 수정 내용이 사라집니다.
